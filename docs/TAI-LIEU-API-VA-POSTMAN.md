# Tài liệu Tổng hợp API, Luồng Nghiệp vụ (Rider, Driver & Admin) và Hướng dẫn Postman

> Bộ tài liệu chi tiết kèm các file JSON import trực tiếp vào Postman được đặt tại thư mục [`postman/`](../postman/):
> - [postman/TAI-LIEU-API-VA-POSTMAN.md](../postman/TAI-LIEU-API-VA-POSTMAN.md) — Đặc tả toàn bộ REST API, mẫu Request/Response và hướng dẫn chạy 1-Click Runner.
> - [postman/POSTMAN-TEST-CHI-TIET.md](../postman/POSTMAN-TEST-CHI-TIET.md) — Hướng dẫn kiểm thử chi tiết Payment Saga, Timeout Reconciliation & Refund Saga.
> - [postman/SwiftRide-EndToEnd.postman_collection.json](../postman/SwiftRide-EndToEnd.postman_collection.json) — Collection E2E luồng chuẩn (WALLET, ghép xe, hành trình, quyết toán sổ cái).
> - [postman/SwiftRide-Card-EndToEnd.postman_collection.json](../postman/SwiftRide-Card-EndToEnd.postman_collection.json) — Collection E2E kiểm thử 3 kịch bản thẻ giả lập (`approved` / `declined` / `unknown`).
> - [postman/SwiftRide-RefundSaga.postman_collection.json](../postman/SwiftRide-RefundSaga.postman_collection.json) — Collection E2E kiểm thử quy trình Admin phê duyệt bồi thường hoàn tiền (`Refund Saga`).
> - [postman/SwiftRide-Gateway.local.postman_environment.json](../postman/SwiftRide-Gateway.local.postman_environment.json) — File biến môi trường chuẩn trỏ qua API Gateway (`http://localhost:5000`).
